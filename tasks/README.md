# Tasks — Local Debug Office

## Summary

Build a standalone `packages/debug-app` that wires together the new `@officexr/sdk` +
`@officexr/core-refactor` stack into a browser-runnable local debug office. No Supabase,
no JaaS, no auth. Proximity detection, voice-room routing, and audio playback are all
exercised — and tested headlessly in Vitest.

**Total tasks:** 11
**Estimated complexity:** Medium-large (new package + 3 new modules + TDD for 4 tasks)

## How to Use These Files

Each task file is a self-contained prompt for an AI agent (or a human implementer). The
agent reads the task file, consults `shared-context.md` for project-wide conventions, and
implements the task.

**Delete each task file after its task is completed.** When all task files are deleted,
the feature is complete.

**These files are ephemeral** — they are regenerated by the planner on each run and should
not be committed to `main` as permanent documentation.
