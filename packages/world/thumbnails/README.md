# Thumbnails

These PNG thumbnails are pre-generated for the bundled block kinds.
Run `pnpm gen:thumbnails` from the repo root to regenerate after catalog edits or new asset-pack installs.

The `thumbnail-manifest.ts` file in `packages/world/src/scenes/` is also auto-generated — do not edit it manually.

## Regenerating

1. Start the studio dev server: `pnpm dev:studio`
2. Run from repo root: `pnpm gen:thumbnails`
3. Commit the new PNGs and manifest.
